## 🌟 Fitur Utama Website

1. **Desain Modern & Responsif**:
   - Tampilan bersih (*clean modern corporate & creative*) dengan palet warna biru korporat (`#2563eb`), ungu kreatif (`#7c3aed`), dan amber prestasi (`#f59e0b`).
   - Sempurna di semua perangkat: Desktop, Tablet, dan Smartphone.

2. **Mode Gelap / Terang (Dark / Light Mode)**:
   - Tombol toggle tema di navigasi atas dengan penyimpanan preferensi otomatis di `localStorage`.

3. **Hero Section Interaktif**:
   - Foto profil asli Anis Fadillah (`assets/img/profile.jpg`) dengan ring gradien halus dan badge status mahasiswa aktif.
   - Efek pengetikan teks dinamis (*dynamic typing animation*) yang menampilkan fokus keahlian.
   - Ringkasan cepat IPK **3.77/4.00**, pengalaman proyek, dan jabatan kepemimpinan di BEM JBS.
   - Tombol aksi cepat: Unduh CV (PDF), Buka Portofolio, dan Chat WhatsApp langsung.

4. **Filter Pengalaman Interaktif**:
   - Tab penyaring kategori (*All*, *Pekerjaan & Magang*, *Organisasi Kampus*, *Proyek Kreatif*, *Volunteer / LO*).

5. **Visualisasi Keahlian (Skills Bar & Grid)**:
   - *Hard Skills* dengan persentase dan progress bar visual.
   - *Soft Skills* dalam format kartu kompetensi interpersonal.
   - Daftar aplikasi/tools digital: Canva Pro, CapCut, Instagram Business, TikTok Creator Studio, Google Workspace, dan Microsoft Office.

6. **Pusat Unduh & Pratinjau Dokumen (Modal PDF)**:
   - Pratinjau langsung file `CV_Anis_Fadillah.pdf` dan `PORTFOLIO_Anis_Fadillah.pdf` melalui modal popup tanpa harus meninggalkan halaman.
   - Opsi *Buka di Tab Baru* dan *Unduh PDF Langsung*.

7. **Kontak Interaktif & Integrasi WhatsApp / Email**:
   - Tombol *Salin Email* & *Salin Nomor HP* dengan notifikasi toast.
   - Formulir pesan cepat yang otomatis menghasilkan tautan percakapan WhatsApp atau email pra-format.

8. **Dukungan Cetak Resume (Print Mode / ATS Friendly)**:
   - Dilengkapi aturan `@media print` sehingga jika ditekan tombol cetak atau `Ctrl + P`, tampilan akan otomatis terformat rapi menjadi lembar resume cetak profesional tanpa elemen web navigasi/tombol.

## 🚀 Cara Menjalankan Website

1. **Buka Langsung di Peramban (Browser)**:
   - Cukup klik dua kali berkas `index.html`, atau klik kanan lalu pilih **Open with Google Chrome / Microsoft Edge / Mozilla Firefox**.
2. **Atau Melalui Local Server (Live Server / Node.js)**:
   - Menggunakan VS Code extension **Live Server**, atau:
   ```bash
   npx serve .
   ```
   Lalu buka URL yang muncul (misalnya `http://localhost:3000`).
